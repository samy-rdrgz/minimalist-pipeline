# Minimalist Pipeline

Lightweight file pipeline for solo artists and small teams — projects,
naming, versions (wip/stable), tracking, and a render farm, all from
Blender's own sidebar.

Requires Blender 4.2+. FFmpeg (optional) if you use the render farm's video
compilation and image-check stages — everything else works without it.

Full documentation, guides, and source:
https://github.com/samy-rdrgz/minimalist-pipeline
