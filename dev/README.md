# dev/

Working documents, not documentation: kept for their history, not kept up to date, never shipped
(`blender_manifest.toml` excludes `dev/`).

- `plan-1.2.md` -- the plan of the work that became 2.0 (in French), phase by phase. Cited by
  NOTES.md and `lib/monitoring/status.py`.
- `snapshot-v7-questions.md` -- the questions settled while redrawing the snapshot page (v7).
- `ui-kit.html` -- the mock-up the page's v7 was drawn from. The page's own component sheet is
  built by `tools/snapshot_kit.py`.

The user documentation is in `docs/`; the developer guide is `CODE.md`, the design decisions
`NOTES.md`.
